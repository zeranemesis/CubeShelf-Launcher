# Mes jeux — Windows, 2 novembre 2026

« Mes jeux » regroupe les jeux installés ou déjà ajoutés de toutes les consoles, séparément du catalogue des ports disponibles. L'accès est présent dans le menu de gauche et sur l'accueil des consoles. F2 l'ouvre depuis toutes les pages du launcher. En Big Picture, des boutons directs sont aussi présents sous les jeux et sur les autres pages ; View / Select ouvre la bibliothèque, tandis que Start reste dédié au menu. X conserve son raccourci sur l'accueil des consoles. B / Échap revient des détails à la bibliothèque puis à l'accueil d'origine.

Le raccourci respecte les fenêtres de dialogue ouvertes et annule une animation de lancement encore en attente. Il ne constitue pas un raccourci global au-dessus d'un jeu externe en cours.

## Contenu

- Programmes présents ou moteurs gérés installés ; ports associés dans le gestionnaire natif.
- Chemins de programme ou de fichier de jeu enregistrés dans les profils.
- Ajouts manuels, même lorsque leur disque ou programme n'est plus accessible, afin de permettre une nouvelle association.
- Versions d'un même jeu regroupées sur une seule carte, avec uniquement les versions déjà présentes dans cette bibliothèque au choix sur la carte. Les variantes par mod restent rattachées au jeu de base.

La recherche couvre titre et console, et les tris existants restent disponibles. Chaque carte indique sa console et conserve le format de sa boîte. Un ajout manuel sans illustration utilise l'état de jaquette indisponible. Le choix des consoles reste accessible séparément ; les nouveaux ajouts manuels prennent la console sélectionnée.

Les profils sont lus une seule fois par actualisation. La présence d'un moteur ou d'un chemin ajouté n'est pas une validation de jouabilité ; la configuration peut encore être nécessaire. Aucun scan automatique de disques ou import de bibliothèques externes n'est effectué : un programme externe doit être ajouté ou associé une fois.

## Validation

- Suite Core : 197 contrôles réussis, dont chargement groupé des profils et indépendance de l'instantané retourné.
- Suite ShelfUi : profils vierges, jeu installé, programme natif associé, image ajoutée, programme manuel absent, versions sans doublon, recherche par console et recherche vide, retour depuis les détails et vers les consoles.
- Souris, clavier et manette simulée : accès personnel depuis l'accueil et le menu, mise à jour des boutons pendant l'affichage Big Picture. Le menu se superpose à l'accueil des consoles sans interception des clics par celui-ci.
- Accès F2 depuis catalogue, réglages et téléchargements ; boutons Big Picture ; View / Select depuis une sous-page ; dialogue ouvert et annulation d'un lancement en attente ; distinction View / Start dans XInput. Un second F2 sur « Mes jeux » conserve la destination du retour.
- Captures contrôlées : bureau, Big Picture, fenêtre 960 × 700. L'en-tête passe sur deux lignes dans les petites fenêtres pour préserver recherche et commandes.
- Compilation Windows x64 autonome réussie, avec les catalogues et les ressources inclus. Les sons doux existants sont conservés.

Ces contrôles ne constituent pas un nouvel essai de partie. La navigation sur manette physique reste à vérifier.
