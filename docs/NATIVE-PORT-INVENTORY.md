# Inventaire des ports natifs — 26 octobre 2026

Recensement des sources primaires et paquets publics disponibles. Aucun lancement de jeu ni extraction de disque utilisateur effectué. Les trois catalogues ne contiennent aucun émulateur généraliste. Les versions encore expérimentales et les sources à compiler restent signalées. L’exhaustivité de tous les projets existants ne peut pas être garantie.
