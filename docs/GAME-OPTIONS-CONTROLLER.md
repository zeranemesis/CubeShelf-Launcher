# Options du jeu avec X

## Windows / Big Picture

Dans le catalogue Classique ou HOME, **X au clavier ou sur la manette** ouvre le menu du jeu sélectionné. Les entrées **Paramètres du jeu** et **Mods du jeu** réutilisent les écrans existants. Le raccourci laisse les saisies, Ctrl+X, les dialogues et le panneau Personnaliser prioritaires. Depuis les consoles, X conserve l'accès à Mes jeux. Le bouton Options du jeu du thème HOME ouvre le même menu.

## Android avec une manette

Le bouton **X de la manette** ouvre les options du jeu sélectionné, en Classique et HOME. A valide, la croix ou le stick parcourt les actions, B et X ferment le panneau. Le bouton tactile Options du jeu de HOME ouvre le même panneau. L'écran de choix des consoles n'ouvre pas d'options de jeu.

Les actions donnent accès à la préparation et aux informations du port, au stockage et aux sauvegardes lorsque le service est disponible, ainsi qu'au retournement du boîtier. Ce panneau ne remplace pas les réglages graphiques propres à chaque moteur. La gestion des mods Android n'est pas implémentée : le panneau l'indique explicitement et ne propose pas d'installation générique non vérifiée.

Sur deux écrans, l'ouverture des options suspend la présentation secondaire. Sa fermeture rétablit la navigation avec le même jeu sélectionné. Une mise en arrière-plan ferme les options ; elles ne reviennent pas au-dessus d'un autre jeu.

Les tests automatisés couvrent le contexte du jeu, A/B/X, le retour HOME/Classique, l'absence de lancement pendant la navigation et les gardes de saisie et de dialogues Windows. Une manette physique reste à tester sur AYN Thor.
