# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de preuve d’exploitation ni de données sensibles dans une issue publique. Contactez le mainteneur du dépôt en privé avec la version concernée, les étapes de reproduction et l’impact estimé.

## Garanties attendues

- les téléchargements sont limités et les artefacts épinglés sont vérifiés par SHA-256 ;
- une archive ne peut pas écrire hors de son répertoire cible ;
- les liens symboliques et noms de fichiers ambigus ne sont pas matérialisés ;
- une release stable Windows doit être signée ;
- le profil local n’est ni inclus dans les artefacts ni supprimé par le désinstalleur.

## Périmètre

Cette politique couvre le launcher, son updater, l’installateur et les workflows de publication. Les images de jeu, mods tiers, Dolphin et PartyBoard conservent leurs propres responsabilités de sécurité.
